# 밸류체인 (Value Chain / 가치사슬)

제품이나 서비스가 최종 소비자에게 도달하기까지의 모든 단계와 참여 기업들의 연결망.

## 상세 설명

밸류체인 분석의 투자 활용:
- 특정 산업의 성장 수혜를 받는 기업들을 체계적으로 파악
- 직접 수혜주 외에 간접 수혜주(부품·소재·장비) 발굴

AI 반도체 밸류체인 예시:
```
설계(NVIDIA) → 파운드리(TSMC) → HBM(SK하이닉스) 
→ 패키지(삼성전기 FC-BGA) → 서버 조립 → 데이터센터 운영
```

로보틱스 밸류체인 예시:
```
완성 로봇(현대차·Boston Dynamics) → 액추에이터·센서 → 제어 SW
```

밸류체인에서 투자 기회를 볼 때:
- 병목(Bottleneck) 구간의 기업이 가장 큰 협상력과 마진 보유
- 진입장벽이 높은 구간(특수 소재·장비 등)이 장기 투자 가치 높음
